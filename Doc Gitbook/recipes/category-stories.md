# Story-style category reels

**Scenario:** *Bloom & Thread*, a clothing boutique, wants round "stories" at the top of its shop page, like the ones shoppers know from social media. There's one per collection: **New in**, **Dresses**, **Knitwear**, **Accessories** and **Sale**.

**Time:** about 20 minutes. **You'll use:** the Carousel layout with the Circle shape.

## 1. One reel per category

Create a reel for each collection. Use a **button** instead of tagged products, so each story leads into the whole category:

| Reel title | Button text | Link |
| --- | --- | --- |
| New in | `Shop new in` | `https://bloomandthread.com/new` |
| Dresses | `Shop dresses` | `https://bloomandthread.com/dresses` |
| Knitwear | `Shop knitwear` | `https://bloomandthread.com/knitwear` |
| Accessories | `Shop accessories` | `https://bloomandthread.com/accessories` |
| Sale | `Shop the sale` | `https://bloomandthread.com/sale` |

Set the **Campaign** on every button to `Shop stories`, so you can measure them together in Statistics.

{% hint style="info" %}
**Cover tip:** circles crop to the centre of the frame. Choose a cover where the product or face is in the middle.
{% endhint %}

## 2. Create the widget

1. **Create widget** → name it `Shop stories`.
2. **Layout:** Carousel. **Reel shape:** Circle.
3. Add the five reels in the order you want them shown.

**Layout step**

* Alignment: **Left**
* Reel width: **88** desktop, **72** mobile
* Gap: **12**
* Title: **Hidden**

**Look step**

* Title: **Below**, so the category name shows under each circle
* Preview before play: **Off**, so the row stays calm
* Border width **2**, border colour your brand accent, to get the familiar "story ring"
* Play button: **Off**

**Player step**

* Slide direction: **Vertical**
* Over the video: **Products**, so the buttons show

Save the widget.

## 3. Place it

Add `[productreels id="…"]` or the **ProductReels** block at the top of your shop page, above the product grid.

## Result

Five small circles with a coloured ring sit above the products. Tapping **Knitwear** opens a full-screen video of the new knits with a **Shop knitwear** button. Swiping up moves to the next story.

## Keep it fresh

Swap the videos in each reel every season. The widget and the page don't need to change. Just open each reel, replace the video and save.
