# Elementor

When Elementor is active, a **ProductReels** widget is added to the Elementor panel automatically. There's nothing to set up.

## Add the widget

1. Edit your page with Elementor.
2. In the widget panel, search for **ProductReels**.
3. Drag it onto the page.
4. Under **Widget**, choose the ProductReels widget to show, for example **Homepage stories**.
5. Click **Publish** or **Update**.

## Change the design

Elementor places the widget. ProductReels styles it.

* **Section, column and spacing:** use Elementor's own layout and Advanced tabs as usual.
* **Reels, layout, colours, player and product cards:** edit the widget under **ProductReels → Widgets**. Changes apply everywhere the widget is used.

## Example: Elementor Theme Builder

A fashion store built with Elementor Pro wants reels on every product page:

1. Go to **Templates → Theme Builder → Single Product**.
2. Edit the template and drag the **ProductReels** widget below the **Product Content** widget.
3. Choose **Styled by customers**.
4. Publish, with the display condition set to **All Products**.

## Tips

* **Nothing shows in the list?** Create a widget first under **ProductReels → Widgets → Create widget**.
* **Popup layout:** a Popup widget floats in a corner of the screen wherever you drop it on the page. Put it anywhere, for example at the bottom of the page.
