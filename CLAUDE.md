## ProductReels 1.1.0 redesign

The 1.1.0 update (new admin flow and layout, refreshed storefront) is driven by `redesign-kit/`.
Before any change to the admin UI, storefront look, data or release files, read `redesign-kit/CONTEXT.md` and `redesign-kit/PROGRESS.md`.
Run one part from `redesign-kit/parts/` per session. Never ship `redesign-kit/` in the plugin zip.
